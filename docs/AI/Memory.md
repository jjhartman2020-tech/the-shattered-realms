# Purpose

The AI Memory framework defines what information should persist throughout a campaign and how that information should influence future gameplay.

Memory allows **The Shattered Realms** to support long-running, reactive campaigns where past events continue to shape future decisions.

Rather than remembering everything equally, the AI should preserve information that meaningfully contributes to continuity, player agency, and world consistency.

---

# Memory Principles

The AI should treat memory as a living record of the campaign.

Every remembered event should improve consistency without unnecessarily increasing complexity.

Memory should be:

- Accurate
- Relevant
- Consistent
- Persistent
- Context-Aware

The AI should avoid storing information that has no meaningful impact on future gameplay.

---

## Persistence

Important events should remain part of the campaign until they are logically resolved or become historically relevant.

Examples include:

- Major Story Events
- Character Development
- Political Changes
- World Discoveries
- Significant Victories
- Significant Defeats
- Long-Term Relationships

These events form the foundation of campaign continuity.

---

## Relevance

Not every detail deserves permanent memory.

The AI should prioritize information that may reasonably influence:

- Future Decisions
- NPC Behavior
- World Simulation
- Player Opportunities
- Quest Progression
- Faction Relationships

Minor details may naturally fade from importance unless they later become relevant.

---

# Memory Categories

The AI should organize campaign memory into distinct categories.

---

## World Memory

Information regarding the persistent state of the world.

Examples include:

- Kingdom Borders
- Political Alliances
- Wars
- Environmental Changes
- Settlements
- Public Events
- Historical Discoveries

---

## Character Memory

Information about player characters.

Examples include:

- Personal History
- Reputation
- Goals
- Achievements
- Relationships
- Character Growth
- Important Decisions

---

## NPC Memory

Information regarding individual NPCs.

Examples include:

- Relationships
- Motivations
- Loyalties
- Knowledge
- Promises
- Personal History
- Opinions of the Players

NPCs should remember events according to what they could reasonably know.

---

## Quest Memory

Information related to campaign progression.

Examples include:

- Active Quests
- Completed Quests
- Failed Quests
- Discovered Clues
- Story Milestones
- Unresolved Mysteries
- Branching Outcomes

Quest history should influence future opportunities whenever appropriate.

---

## Event Memory

Records of significant campaign events.

Examples include:

- Battles
- Treaties
- Festivals
- Natural Disasters
- Assassinations
- Discoveries
- Major Public Incidents

Events should remain part of the world's history and continue influencing future gameplay when appropriate.

---

# Maintaining Memory

Campaign memory should evolve naturally as the world changes.

The AI should continually update existing memories rather than creating unnecessary duplicates.

When significant events occur, relevant memory categories should be updated to reflect the new campaign state.

Examples include:

- Completing a quest.
- Forming or breaking an alliance.
- Defeating a major enemy.
- Discovering a new location.
- Changing political leadership.
- Establishing a new settlement.

Memory should remain synchronized with the current world state.

---

# Memory Retrieval

The AI should retrieve only the information relevant to the current situation.

When making decisions, the AI should prioritize memories that directly affect:

- The current location.
- Active participants.
- Ongoing quests.
- Recent events.
- Relevant NPCs.
- Current political or environmental conditions.

Older memories should remain available but should only influence decisions when logically applicable.

---

# Continuity

Memory exists to preserve continuity across the entire campaign.

Players should feel that the world remembers their actions.

Examples include:

- NPCs recognizing previous encounters.
- Settlements recovering from earlier events.
- Factions responding to past decisions.
- Previously discovered locations remaining known.
- Earlier choices unlocking or preventing future opportunities.

Continuity should emerge naturally from remembered events rather than being artificially imposed.

---

## Memory Boundaries

The AI should distinguish between permanent and temporary information.

Permanent memory includes information that has lasting impact on the campaign.

Temporary memory includes information that is only relevant for a limited period, such as:

- Current conversations.
- Short-term objectives.
- Temporary conditions.
- Active combat situations.
- Immediate environmental details.

Temporary information should naturally expire once it is no longer relevant, while permanent memory should remain available throughout the campaign.

---

## Respecting Perspective

Memory should always respect perspective.

Different participants may remember the same event differently based on:

- What they witnessed.
- What they were told.
- Their personal beliefs.
- Their level of knowledge.
- The passage of time.

The AI should avoid treating every remembered event as universally known or interpreted.

---

# Summary

The AI Memory framework preserves the history of the campaign while ensuring that information remains relevant, organized, and consistent.

Rather than storing every detail indefinitely, the AI should remember the events, relationships, and world changes that meaningfully influence future gameplay.

By maintaining accurate memory, respecting individual perspectives, and preserving continuity, the AI creates a living world where past actions continue to shape future adventures.
