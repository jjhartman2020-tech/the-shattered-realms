# Shattered Realms AI

## Vision

Shattered Realms AI is an AI-powered RPG where every decision permanently changes a living world.

The goal is to build the most immersive AI Dungeon Master ever created, featuring:

- Persistent campaigns
- Living NPCs
- Adaptive enemies
- Tactical combat
- Long-term memory
- AI-generated maps and characters
- Automatic recaps
- A world that continues changing even when you're offline

This repository contains the design documents and source code for the project.
